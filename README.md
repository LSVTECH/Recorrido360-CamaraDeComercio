# Recorrido Virtual 360° — Cámara de Comercio de Cartagena

Recorrido virtual en HTML, CSS y JavaScript (WebGL / WebXR), reconstruido a partir del proyecto 3DVista.

- Navegación 360° con hotspots, menús de sedes y CISES, paneles informativos y videos.
- Modo VR: visores con WebXR (Meta Quest), Cardboard en móviles y vista previa en PC.
- Descarga para ver sin conexión (botón "Descargar").

Sitio: https://lsvtech.github.io/Recorrido360-CamaraDeComercio/
